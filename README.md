# Aesthetic Puzzles

Aesthetic Puzzles turns classic puzzles and brain teasers into visual, interactive, and beginner-friendly learning experiences. <br />
https://shelvia-w.github.io/aesthetic-puzzles/

![Alt](https://repobeats.axiom.co/api/embed/251e45a8a486428ba01a1cd6d949675b1a2b59e3.svg "Repobeats analytics image")

Features:
- **Classic puzzle collection**: explore popular brain teasers, logic puzzles, and probability puzzles.
- **Interactive visualizers**: experiment with puzzle setups through hands-on simulations.
- **Step-by-step walkthroughs**: understand the reasoning behind each solution clearly.
- **Aesthetic infographics**: remember key ideas through polished visual summaries.
- **Beginner-friendly design**: make tricky puzzles feel approachable and fun.
